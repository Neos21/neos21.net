デスクトップマシン Galleria XA7C-R57T の PC ケースファンを2つ交換した

2026年3月に購入したデスクトップ PC の Galleria XA。最近どうもファンがガラガラと音を立てていてうるさかったのと、大きな振動を引き起こしているところがあったので、原因を調査して交換することにした。

デカい筐体なので、ケースファンがたくさん付いていた。前面に2つ、上面に2つ、背面に1つのファンがあり、CPU は簡易水冷。

まずどのファンが異音や振動を立てているのか確認するため、ファンごとに回転数を変えてみることにした。以下の「FanControl」という Windows 用フリーソフトを使うと、ファンを自動特定してくれて、ファンごとに回転数を変更できた。ついでに GPU ファンまで制御できたので、「まさか GPU ファンが壊れてるんじゃなかろうな？！」というチェックも出来た。GPU ファンは今回問題なかった。

  • Rem0o/FanControl.Releases: This is the release repository for Fan Control, a highly customizable fan controlling software for Windows.

異音・振動を引き起こしていたのは、ケース上面の1つと、ケース背面の1つだった。

原因となっていたファンを取り外し、型番で検索し、サイズや回転数などの仕様を調査。マザーボードは ASRock B860 TW というモノで、その仕様書も確認して、マザボのどこと、どんなピンで繋がっているかなども確認した。

そしたら同じサイズで、回転数などの仕様が同等の類似品を検索して、Amazon で購入し取り付けた。寸法さえ合えば、複数あるケースファンの1つなので、回転数なんかは既存品と完全一致しないモノでもさして問題にはならない。最後は値段で選んだ。

ファンの枠の部分に矢印などの印が付いていて、ケース内の吸気・排気の向きが元と同じになるように気にしつつ取り付けた。

ケース上部は 12cm 四方のファンで、LED で光らすための3ピンもあったのだが、光らなくていいのでこの際に全部外してしまった。4ピンの PWM 接続だけで OK。ガラガラとうるうさかったのはコレで解決。

ケース背面は 14cm 四方のちょっと大きなファンで、厚みが他のパーツに干渉しないかだけ確認して好感。コレが大きな振動を起こしていたので解消して良かった。

ついでに、BIOS で出来るファンコントロールも見直して、性能全振り状態だったところから静音性重視に切り替えた。

画像でのレポートとかもナシで文章だけでお届けしましたが、快適になりましたのでコレでおしまいです。ｗ
