本サイト開設から24年経った

2002年10月9日に開設した本サイト。2026年10月9日で24周年を迎えた次第。当日はこのことをすっかり忘れていました。

このサイトの大まかな変遷は以下のとおり。

  • 元々は http://neo.s21.xrea.com という XREA の無料サーバで長らく運営していた。このアカウント、ウェブページは現在も残っている
  • 2020年11月1日に現在の neos21.net ドメインを Value Domain で取得し、同時に XREA Plus という広告解除サービスを契約していた
  • しかし XREA Plus の金額が高かったため、2021年10月26日頃に解約し、現在は GitHub Pages を使ってホスティングし、カスタムドメインを適用することで運用している
  • ドメインの DNS 管理も、元々は Value Domain で行っていたが、2025年1月16日よりネームサーバを設定、DNS 管理は現在 Cloudflare に移管している

サイトの開発環境としては以下のように変遷してきた。

  • 開設当初は「ホームページビルダー 2000・2001・v6・v6.5」あたりまでを使用していた。ホームページビルダーは FTP アップローダのソフトも内蔵していたのが便利だった
  • 手打ち HTML に移行してから、2004年10月頃からは ez-HTML エディタを使うようになり、複数ファイルをまたいだ一括置換には TextSS を愛用していた。ホームページビルダー付属の FTP アップローダだけは引き続き利用していたような
  • 2017年頃からエディタは VSCode 一本になり、XREA へのアップロードが必要な時は FFFTP を使っていた
  • 2017年9月頃より、静的な HTML をただただアップロードするのではなく、Node.js で開発環境を構築してサイトをテンプレート化、開発サーバを用意したり CSS のビルドなども行うようになった
    • 具体的な利用パッケージはその時々で違い、2017年頃はまだ Gulp ベースで Babel や Browserify を使っていたり。中でも @neos21/gulp-template-html という自作のテンプレートシステム (Mustache に近いモノ) はその概念的には2026年現在も利用箇所がある
    • ホスティング先に XREA を利用していた頃は FTP アップロードを Node.js スクリプトを組んで実行したりなどもしていた
    • 2020年11月頃より、Unified および Remark・Rehype を利用し始め、元ファイルが Markdown でも HTML でも、ほぼ同じ結果になるようにビルドするシステムを自作構築した
    • ローカル開発用サーバは sirv-cli を使っていた瞬間もあったが、今は BrowserSync に一本化している。コレはだいぶ古くなった気もするが、自前の HTML ビルドシステムを上手く動かすには BrowserSync くらいの柔軟なカスタマイズ性が必要なところもあり、いまだ愛用中
    • CSS のビルドも CleanCSS を使うように変えた後、2026年5月に PostCSS・cssnano に切り替えたり、チマチマと変化はあった

近年は TypeScript 自身もコンパイラを Go 言語に移行したり、Vite は内部で Go 製の esbuild を使っていたり、Vite を含めた次世代ツールチェーンである Vite+ では Rust 製の Oxlint・Oxfmt・Rolldown を使っていたりと、開発・ビルドの高速化のために Node.js 向けのツールの内部でも Go やら Rust やらが使われることも多くなってきたが、自分のサイトのビルドシステムは全て Node.js (ESM) で書いている。TypeScript ですらない。ローカルマシンのスペック活用してブン回せばいいやと思っているので、fs/promises ではなく fs の Sync 系 API でファイルの読み書きをしているし、並列処理とかもしてない。サイトを構成するファイルは大体3800ファイルほどあり、そのほとんどが HTML か Markdown なので Unified (Remark・Rehype) を用いた変換を行っているが、全体ビルドを行っても16秒くらいで終わるので個人的には不満なし。普段は変更があったファイルだけ差分ビルドするようにしてるしね。今風らしくない、カッコ良くはないかもしれないけど、自分で作ったとおりに動いている、というところが自由度も高くて満足している。

2016年1月から2020年12月末までは「はてなブログ」の方が盛んに更新していて、このサイトはほったらかし状態だったけど、2020年末にはてなブログを閉じ、翌2021年1月にははてなブログで公開していた記事を全て本サイトのブログに移行させた。はてなブログで書いていた記事は全部で2447件あったようで、それが前述の約3800ファイルの大半を占めている感じ。ブログを本サイトに一本化した2021年から現在までの執筆本数は638件で、休職し始めた2022年からの更新頻度はかなり下がっている。

ホームページをやっている理由や目的については、

  • そもそもホームページ製作を始めた当初は、「ひめにゃーす氏の『ポケモンだいすきクラブ』のようなサイトを自分も作りたい！」とか、「『Outside』のような面白 Flash を作りたい！」とか、そんな理由で始めた
    • ポケモンだいすきクラブ (ひめはじめ a.k.a ひめにゃーす氏) : http://www.maccentral.or.jp/pokemon/・http://pokemon-daisuki.com
    • Outside (GiornoBrando a.k.a chickenbush 氏) : http://www8.plala.or.jp/outflash/・http://outsideflash.com/・現 https://giornobrando.com/products/outsideflash/
  • それから徐々に「HTML 小技集」とか「Strict で Valid な HTML とは」みたいなことにコダワり始め、「ホームページ作成講座」みたいなコンテンツもやり始め…
  • 写真や動画を撮って、それを告知する場所になっていったり…
  • フルーツメールやらマクロミルやら、そうした「お小遣い稼ぎサービス」を使い始めてからは「ホームページがちょっとした金になるかも！？」という理由で継続し…
  • 転職を意識し始めた2016年からは、技術メモを残す意図で「はてなブログ」を始めたが、PV 数も稼ぎやすかったために Google AdSense の収益をぼちぼちと上げ、サイト運営というモノを止めづらくなる (笑)
  • 2020年には技術的な飽きが来たこと、子供が生まれて生活が変わったこと、などが重なったので、「他人に向けた記事を書くブログ」という媒体から離れて「個人サイトへの回帰」を考えるようになった。そこで元々開設して放置気味だった本サイトに戻ってきた
  • 以降は惰性というか、自分の人生を記録する場所として、今この時代を生きた一人の一般人が、生き証人として今を記録する、という感じでのんびりやっている

という感じだろうか。基本的には「日記を書いていたらそれがたまたま全世界に公開されていただけ」みたいな感覚である。ｗ アドセンス収益もこのサイトに集約した2021年からはガタ落ちしてて、サイト絡みでかかる費用といえばドメイン更新代だけなのにそれすらも赤字だし、金銭的なメリットもない。自分は仕事においてこの名義も一切公表していないので、公私を混ぜて登壇とかして技術界隈でインフルエンサー的に活動して会社の知名度に貢献、みたいなこともない。完全に個人の趣味。明確な意味も目的も、もはやない。12歳・中1の頃からずっとやってきたことだから今日もやってる、というだけ。

人生的にはどんな感じだったか、っていう話はココ1・2年はたびたび記事にしてるので、一旦振り返りはいいかな。来月11月からどうなるか、間もなく確定する直前なう、という段階なので、確定して、次のフェーズで生活して落ち着いたらまた話します。

最近は大体1日 300PV 程度 (きっと Bot も多数含む) のショボショボサイトですが、これからもぼちぼちやっていくと思います。ドウゾよろしく。
